# Messenger Pigeon

## About

Messenger Pigeon is a communication app designed to allow users to
send text, upload images, and exchange files to other users.

It allows for multiple chats, with each message being time stamped.

## Reflections:

- Keirwin: I think a UI mockup as static images would require many more images to address more fine detail like hover tool tips, more nested pages, context menus, etc. There may have been better tools for making a mockup, like art programs or even power points to enable animation. Overall I think this mock up is a good step towards having a general idea of what to work on to get the skeleton of the project made. It also allowed for much faster work done than coding HTML buttons and containers, or CSS.
